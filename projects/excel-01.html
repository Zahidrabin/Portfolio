1 Introduction & Background

Project Overview

This project addressed the challenge of working with a raw multi-source e-commerce export that combined sales records from three regional warehouses into a single feed. The dataset arrived with inconsistent date formats, duplicate SKU entries across regions, mixed currency symbols, and an unstructured product category taxonomy.

The goal was to produce a single clean, analysis-ready table that downstream dashboards and financial models could reliably consume — without manual intervention every reporting cycle.

3 Insights & Analysis

Key Findings & Data Quality Improvements

The standardization process exposed critical data quality issues that would have introduced significant margin errors in downstream financial models. Power Query's M Language was used to apply conditional transformation logic non-destructively, preserving the original source columns.

  • Identified 4,217 duplicate SKU entries caused by case inconsistency in product codes across three warehouse feeds — resolved via a custom lowercase normalization step.
  • Detected 3 conflicting date formats (DD/MM/YYYY, MM-DD-YY, Unix timestamp) across regional exports; unified to ISO 8601 using M-language date parsing functions.
  • Currency normalization reduced a 12% revenue discrepancy that had been silently inflating UK region totals due to mixed GBP/EUR symbol handling.
  • Taxonomy re-mapping collapsed 47 raw category labels down to 8 standardized parent categories, enabling consistent pivot reporting.
