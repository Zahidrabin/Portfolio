EnginePostgreSQL 15

1Introduction & Background

Project Overview

A production PostgreSQL database ingesting from two upstream ERP systems had accumulated significant duplicate and malformed records over 18 months. This project developed a suite of idempotent SQL scripts to identify, isolate, and safely remove duplicate rows while fixing NULL imputation gaps and standardizing column types.

2Initial Setup · Raw Schema & Duplicate Identification

Schema Audit & Duplicate Detection Query

dedup_audit.sql
-- Step 1: Identify duplicate records using ROW_NUMBER window function WITH ranked_records AS ( SELECT *, ROW_NUMBER() OVER ( PARTITION BY order_id, customer_id, product_sku ORDER BY created_at DESC ) AS row_num FROM raw_orders ), -- Step 2: Flag duplicates (row_num > 1) duplicates_flagged AS ( SELECT order_id, customer_id, product_sku, created_at, row_num FROM ranked_records WHERE row_num > 1 ) -- Preview count before deletion SELECT COUNT(*) AS total_duplicates, MIN(created_at) AS oldest_duplicate, MAX(created_at) AS newest_duplicate FROM duplicates_flagged;
3Insights & Analysis

Findings & Data Quality Outcomes

The deduplication audit revealed a systemic issue originating from a batch import failure 6 months prior that re-inserted entire daily partitions without checking for existing records. The schema standardization also uncovered hidden NULL patterns masked by empty string storage.

  • Detected 12,847 duplicate rows (3.2% of total dataset) originating from a failed ETL batch re-run in October.
  • NULL imputation strategy resolved 8 columns containing mixed NULL and empty-string values that caused aggregate queries to return incorrect totals.
  • Type casting corrected revenue columns stored as VARCHAR, enabling numeric aggregations to run without CAST overhead on every query.
  • Post-cleanup, query performance on the orders aggregate improved by ~40% due to reduced table bloat.

Post-Deduplication Validation Query & Results

-- Final validation: confirm zero duplicates remain SELECT COUNT(*) AS total_rows, COUNT(DISTINCT order_id) AS unique_orders, SUM(CASE WHEN revenue IS NULL THEN 1 ELSE 0 END) AS null_revenue_rows FROM clean_orders;
